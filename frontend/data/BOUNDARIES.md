# 창원 법정읍·면·동 경계 참고자료

문서 갱신: **2026-10-17** · [사용 안내](../../README.md) · [데이터 정의](../../docs/DATA_METHODS.md)

## 경계 출처와 정확도

- 원출처: 국가공간정보포털·브이월드 법정읍면동 경계, 2023-07-29 배포본.
- 가공출처: https://github.com/KnellBalm/kr-admin-geojson/tree/3a859f2a45be8acf8237d9eefd9565f99cc603da
- 위 저장소 README는 원본 및 가공 결과물 모두 출처 표시 조건으로 자유 이용 가능하다고 명시한다. 본 서비스는 두 출처를 화면과 파일에 표시한다.
- 입력은 WGS84 변환 후 0.0005도 단순화된 자료다. 추가 단순화는 하지 않았다. 원본의 현재 경계 정확성을 보증하지 않는다.
- 2026-10-17 서비스 지역 목록 204개의 법정동 코드와 이름에 모두 일치함을 검증했다. 코드 일치는 2023년 이후 경계 변경이 없음을 보증하지 않는다.
- 법정동 `EMD_CD` 8자리에 `00`을 붙여 서비스 법정동 10자리 코드와 연결한다. 가공 자료의 `HJD_CD`(행정동)는 사용하지 않는다.
- 면적은 pyproj.Geod의 WGS84 타원체 면적이며, 외곽에서 내부 홀 면적을 뺀 MultiPolygon 합계다. 단순화된 경계로 계산하므로 공식 등록면적과 다를 수 있다. 화면은 '약' 및 참고 면적임을 표시한다.
- 통계 조회월과 경계 기준일은 독립적이다. 과거 경계 복원, 토지 경계 확인, 법적 판단 용도로 사용하지 않는다.
- 최신 공식 브이월드 파일 다운로드는 작업 당시 502 오류로 확보하지 못했다. 최신 파일 교체 시 법정동 코드·좌표계·라이선스·출처일·섬과 홀 보존을 재검증해야 한다.

`scripts/build_region_boundaries.py`는 입력 커밋과 SHA256을 고정하며 재생성할 수 있다. 경계만 보기에서는 자체 호스팅 JSON을 사용하며 외부 지도 요청이나 API 키가 필요하지 않다. 배경을 선택하면 아래 제공자의 외부 타일을 요청한다.

## 배경지도

- 배경 선택: 경계만 / 도로·건물(OpenStreetMap) / 지형·등고선(OpenTopoMap, OSM·SRTM).
- 두 배경은 XYZ Web Mercator이다. 법정동 GeoJSON 경위도를 동일 투영으로 변환해 겹친다. 면적은 기존 WGS84 타원체 계산값을 유지하며 화면 투영으로 다시 계산하지 않는다.
- 사용자가 선택한 현재 화면의 타일만 직접 요청한다. 브라우저 기본 캐시·Referer를 유지하고 사전 수집·오프라인 저장·프록시를 사용하지 않는다. 제공자 출처 및 라이선스를 지도 안에 표시한다.
- 정책: https://operations.osmfoundation.org/policies/tiles/ 및 https://opentopomap.org/about (출처표시·동일조건변경허락).
- 배경지도 장애 시 경계만 보기로 전환할 수 있다. 배경 갱신시점·2023년 경계 기준일·통계 기준월은 서로 다를 수 있다.
- 위성영상은 미포함이다. 공급자 인증키 및 허용된 이용권한을 확보한 뒤 별도 연계해야 한다.
