# 창원 법정읍·면·동 경계 참고자료

- 원출처: 국가공간정보포털·브이월드 법정읍면동 경계, 2023-07-29 배포본.
- 가공출처: https://github.com/KnellBalm/kr-admin-geojson/tree/3a859f2a45be8acf8237d9eefd9565f99cc603da
- 위 저장소 README는 원본 및 가공 결과물 모두 출처 표시 조건으로 자유 이용 가능하다고 명시한다. 본 서비스는 두 출처를 화면과 파일에 표시한다.
- 입력은 WGS84 변환 후 0.0005도 단순화된 자료다. 추가 단순화는 하지 않았다. 원본의 현재 경계 정확성을 보증하지 않는다.
- 2026-10-17 서비스 지역 목록 204개의 법정동 코드와 이름에 모두 일치함을 검증했다. 코드 일치는 2023년 이후 경계 변경이 없음을 보증하지 않는다.
- 법정동 `EMD_CD` 8자리에 `00`을 붙여 서비스 법정동 10자리 코드와 연결한다. 가공 자료의 `HJD_CD`(행정동)는 사용하지 않는다.
- 면적은 pyproj.Geod의 WGS84 타원체 면적이며, 외곽에서 내부 홀 면적을 뺀 MultiPolygon 합계다. 단순화된 경계로 계산하므로 공식 등록면적과 다를 수 있다. 화면은 '약' 및 참고 면적임을 표시한다.
- 통계 조회월과 경계 기준일은 독립적이다. 과거 경계 복원, 토지 경계 확인, 법적 판단 용도로 사용하지 않는다.
- 최신 공식 브이월드 파일 다운로드는 작업 당시 502 오류로 확보하지 못했다. 최신 파일 교체 시 법정동 코드·좌표계·라이선스·출처일·섬과 홀 보존을 재검증해야 한다.

`scripts/build_region_boundaries.py`는 입력 커밋과 SHA256을 고정하며 재생성할 수 있다. 지도 런타임은 자체 호스팅 JSON만 사용하고 외부 API키나 지도 CDN을 요구하지 않는다.
