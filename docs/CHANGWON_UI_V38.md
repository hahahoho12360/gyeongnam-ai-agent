# 창원 화면 개선 v3.8.1

채팅을 첫 화면 중심으로 배치하고 창원의 산·바다·벚꽃을 표현한 색상과 배경을 적용했습니다. 지역 직접 선택은 하단의 **알고 싶은 지역 바로 알아보기**에서 이용합니다.

- 질문에 명시된 지역은 서버에서 먼저 확정하고 응답의 resolved_region으로 요약·그래프를 동기화합니다. 같은 이름의 지역은 구를 함께 입력합니다.
- 데이터 관리: 날짜·값·메모 추가, 수정, 삭제. 내 기록 분석은 /api/data/summary를 AI 컨텍스트로 전달합니다.
- 대화 목록: 불러오기, 삭제, 새 대화. 저장된 분석 지역과 분석 대상을 복원합니다.
- 답변: 안전한 Markdown 표시, 글자 확대, 데이터에서 확인한 발견과 의미 및 검증되지 않은 가설을 구분합니다.
- 그래프: 실제 표시 기간, 단위, 관측점의 월·값, 비교군별 시작 관측값. 결측 구간은 선으로 잇지 않습니다.
- 최신 상태·소스 상태 확인은 하단으로 이동하고 설명과 툴팁을 제공합니다.
- 유사 지역과 무작위 비교 지역은 인접지역으로 표시하지 않습니다. 경계 인접자료 등록 및 과거 인구 보완은 별도 작업입니다.

검증: `python -m pytest -q tests` 76개 통과, `node --check frontend/app.js` 통과. 운영 API에서 적현동 선택 상태로 가포동 질문을 보내 resolved_region=4812510100, 인구 5307명, get_population_trend 도구 호출 및 대화 저장을 확인했습니다.

배포: main 변경에 연결된 Render와 Vercel 자동 배포를 사용합니다. API /openapi.json의 버전 3.8.1과 Vercel의 새 화면을 확인합니다. 빈 자료는 0으로 해석하지 않습니다.
