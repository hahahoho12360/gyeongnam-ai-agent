# 창원 홈페이지 UX v4.1

- 최초 접속은 지역 미선택 상태입니다. 지역 목록만 읽고 지역 통계는 자동 조회하지 않습니다.
- 질문 예시 5개와 ‘다른 질문 보기’를 유지합니다. 채팅 입력은 분석 대상 바로 아래입니다.
- 첨부 창원 풍경 원본을 WebP 배너로 변환했습니다. 상단 내비게이션과 창원시 마크는 추가하지 않았습니다.
- 직접 조회는 구·법정읍면동 선택 후 ‘지역 살펴보기’로 실행합니다. 조회·상태 확인은 진행/완료/오류를 버튼 근처에 표시합니다.
- 그래프 기본 기간은 최신 저장월까지 최근 12개월입니다. 답변 길이와 독립적입니다. 시작/종료월 조회는 최대 120개월이며, 요약표는 종료월 기준입니다. 종료월 자료가 없으면 다른 월로 대체하지 않습니다.
- CSV/JSON은 마지막으로 적용한 기간을 사용합니다. 아직 적용하지 않은 월 입력 변경은 다운로드에 반영하지 않습니다.
- 대화 복원은 저장된 지역 ID, 기존 resolved_region, 도구 기록, 명확한 사용자 메시지 순서로 지역을 확인합니다. 지역을 확인하지 못하면 기존 요약을 지우고 선택을 요청합니다.
- 존댓말 해요체, 유사 지역 용어, 간결한 주의사항을 적용했습니다. 자동 비교 제목과 선정 근거의 반복 문구를 제거했습니다.
- 지역 뉴스는 Google News RSS에서 최근 30일의 창원+정확 지역명 제목, 날짜, HTTPS 출처 링크가 있는 한 건만 추가합니다. 기사 본문 분석이나 사실 검증은 수행하지 않으며, 통계의 원인으로 단정하지 않습니다. 없음/연결 오류는 통계 답변을 막지 않습니다. 서버 메모리 캐시 30분, 외부 요청 연결/읽기 시간 제한 적용.
- 개인 기록 분석은 지역 뉴스 검색을 하지 않습니다.
- Firebase 공식 데이터와 진행 중인 수집 액션 코드는 변경하지 않았습니다.

## 검증

- Python 전체 테스트 95개 통과: 기간 경계·종료월 결측·내보내기 일치·기사 날짜/지역/링크 필터 포함.
- Node JavaScript 구문 검사 통과.
- DOM 통합 시험 통과: 초기 자동조회 없음, 예시 5개/교체, 입력 순서, 직접 조회, 기간 적용, 두 상태 버튼, 대화 복원, 오류 후 재시도.
- 실제 기사 표시는 지역별 검색 결과에 따라 없을 수 있습니다. 제목 검색 결과는 기사 본문 검증을 뜻하지 않습니다.
