# 창원 과거 인구 수집: 총계 우선 정책

## 목적
개별 법정동의 과거 인구 결측 때문에 시 전체 보완이 중단되는 상황을 줄입니다. 기존 공식 API, 월별 Firebase 저장, 성공 월 체크포인트를 유지합니다.

## 기본 정책 totals_first
- 과거 월에 한정합니다. 시 전체와 5개 구 공식 인구 총계를 모두 요구하며, 기존 성별·세대 총계 대조도 유지합니다.
- 독립적인 개별 지역 공식값이 없고 저장 인구도 비어 있다면 중단 대신 unresolved_missing_population 경고를 기록합니다.
- null을 0으로 채우거나 다른 월의 값을 복사하지 않습니다. 자료가 있는 지역의 알려진 공식값 불일치는 계속 차단합니다.
- 최신월의 개별 공식값 검증, API 오류, 코드·기준월 불일치, 수집한 성별·연령 합계 검증은 완화하지 않습니다. 보완 대상 하위 리의 API가 비는 경우도 계속 조사 대상으로 차단합니다.
- 총계가 일치해도 지역 간 오배분이 상쇄될 수 있습니다. 과거 개별 지역의 독립 검증 완료를 의미하지 않습니다.

## 실행
GitHub Actions → Changwon population history repair v3.7 → Run workflow → main → validation_policy=totals_first → Run workflow. 이전 실패 실행의 Re-run이 아니라 새 main 실행을 시작합니다. strict를 선택하면 기존 개별 결측 차단 정책으로 실행합니다.

성공한 월은 Firebase 체크포인트를 읽어 건너뜁니다. 한 실행은 최대 6개월, 수집 시간 한도는 180분이며 미완료 월이 있으면 동일 정책으로 후속 실행을 요청합니다. 실패하면 자동 반복하지 않고 결과 파일을 남깁니다.

## 완료 판정
Actions Summary와 staged_validation_YYYY-MM.json에서 총계 검증, 결측 경고, population_coverage를 따로 봅니다. status=passed는 저장을 진행할 검증 기준 통과이며 quality_status=passed_with_warnings는 결측이 남아 있음을 뜻합니다. 전체 실행 완료 후 지수를 재계산하되 index_meta.population_missing으로 인구 결측을 구분합니다.

이번 실패의 확인 근거: 실행 38040000232의 2022-10은 1023269명으로 통과·저장, 2022-11은 1022641명 및 5개 구 총계가 일치했지만 적현동 4812311700의 null만 차단 항목이었습니다. 이번 정책에서는 그 항목을 경고로 남깁니다.

검증: 전체 자동테스트 79개 통과. totals_first에서 결측 유지·경고·통과, strict에서 차단, 총계 불일치·지역별 알려진 값 불일치·구 총계 누락 차단, 최신월 적용 거부를 확인했습니다.
