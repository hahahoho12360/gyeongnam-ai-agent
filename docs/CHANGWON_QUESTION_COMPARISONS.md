# 질문에 맞춘 자동 비교와 지역 소개

- 자동 비교는 유사 지역 최대 2곳과 무작위 비교 지역 1곳이다. 인근 지역은 화면, 그래프, AI 비교 컨텍스트와 비교 보완 문단에서 제외한다. 경계 원본·등록된 인접관계·수집 작업은 변경하지 않는다.
- 질문에서 청년, 고령 인구, 가구 구성, 인구, 주택 매매, 임대, 상권·생활편의, 건축 주제를 분류하여 지표 가중치를 바꾼다. 별도 주제가 없으면 종합 지표를 쓴다.
- 대상과 같은 기준월이며 선택 지표가 모두 있는 창원 지역을 비교한다. 결측·no_data는 0으로 바꾸지 않는다. 해당 주제의 대상 지표가 전부 없으면 종합 지표로 대체했다는 정보를 제공한다.
- 가장 가까운 지역은 유지하고, 다음 지역은 가까운 후보 최대 5곳에서 질문 내용을 반영한 가중 추출로 고른다. 적절한 후보가 적으면 비교군이 그대로일 수 있다. 지역·월·질문이 같으면 결과는 재현된다.
- 질문은 도구 호출, 채팅 이후 대시보드, 기간 변경, 저장 대화 복원에 전달한다. 직접 지역을 조회하면 종합 비교로 돌아간다.
- 지역 소개는 질문 밖의 지리·역사·지명·생활문화 등 일반 배경을 간단 1문장, 기본 2문장, 상세 최대 3문장으로 안내하도록 지시한다. 수치 분석은 공식 저장 자료를 계속 사용한다.
- 선택적 한국어 위키백과 조회는 이름과 창원시·해당 구가 확인되는 정확한 항목만 참고한다. 동 단위는 법정동 설명이 없는 행정동 항목을 배제한다. 출처를 찾지 못하면 확실한 일반 상식만 사용하고, 모르는 지명 유래·시설·현재 소식을 만들지 않도록 지시한다. 모든 204개 지역의 백과사전 항목 존재를 보장하지 않는다.
- 백과사전은 공식 통계가 아니다. 최근 소식은 기존 날짜·제목·출처 기반 처리와 구분한다. 외부 조회 실패가 통계 조회나 채팅을 중단시키지 않도록 제한시간과 캐시를 사용한다.

검증: 주제별 실제 순위 차이, 같은 질문 재현성, 두 번째 유사 지역 다양성, 결측/기준월/범위 제외, 중복 비교 방지, 월 단위 일괄 조회, 인근 지역 보완문 제외, 소개 길이 컨텍스트, 다른 도시·행정동 오인 방지, 외부 조회 실패 처리. 화면의 기존 5개 질문 예시·다른 질문 보기·5개 추세 버튼·기간 제한을 유지한다.
