## 실행 흐름

- 최신월: 23개 법정동 + 8개 읍면의 하위 법정리 112개를 기존 API로 조회. 코드/월/중복/성별합/연령합/세대/1인세대 검사. 공식 CSV와 지역별 인구/성별/연령/1인세대 및 시구 인구/세대 합계 대조. 모든 검사 후 기존 Firebase 문서 백업 파일 저장 및 batch 원자 적용.
- API 원자료는 Firebase에 저장하지 않는다. 월별 집계와 수집 근거만 저장한다. 원본 응답은 실행 검증 artifact에 남긴다.
- 최신월 성공 시 과거 workflow 자동 시작. 3개월 API 묶음 조회를 기준월별로 분리. 실행당 최대 6개월, 180분 경계에서 이어 실행. Firebase rollout_reports의 월별 체크포인트를 사용한다.
- 과거월은 공식 시·구 인구/세대/남녀 합계 및 API 내부 연령/성별/세대 정합성을 확인한다. 독립된 법정동별 과거 48개월 CSV 전체 대조는 하지 않았으므로 그 수준의 검증 완료로 표현하지 않는다.

- 자동 재시도는 정상 배치의 미완료 상태에만 실시. API/검증/쿼터 실패는 중단하고 artifacts와 체크포인트를 남긴다.
