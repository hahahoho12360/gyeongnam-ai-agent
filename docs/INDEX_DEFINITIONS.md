# 파생지표와 Composite Index 정의 (v1.0)

> 아래 Composite Index와 일부 Proxy는 **프로젝트 자체 정의 지표**이며 공식 통계가 아니다. 실제 제출에서는 UI와 README에 이 점을 명확히 표시한다.

## 파생지표 16종
1. 인구증감률(MoM/YoY)
2. 청년인구비율 = 20~39세 / 총인구
3. 고연령인구비율 = 65세 이상 / 총인구. **65+ 직접값이 없고 10세 구간만 있으면 60+ / 총인구를 Proxy로 사용**하며 `older_population_basis=60_plus_proxy`, `older_population_is_proxy=true`를 함께 저장한다.
4. 1인가구비율 = 1인세대 / 전체세대
5. 소형가구비율 = (1인+2인 세대) / 전체세대
6. 공동주택 공급비율 **Proxy** = 공동주택 세대수 / 주민등록 세대수
7. 노후주택비율 = 30년 이상 건축물 / 전체 건축물
8. ㎡당 매매가격 = 개별 거래가격/전용면적의 월 중앙값
9. 매매가격 YoY
10. 거래회전율 = 월 매매건수 / 공동주택 세대수
11. 전세가격 = ㎡당 중앙 전세보증금 또는 명세상 가능한 중앙값
12. 전월세 거래량
13. 월세화 비율 = 월세거래 / 전체 임대거래
14. 인구 1천명당 상가수
15. 상가 순증감 = 당월 Snapshot 업소수 - 전월 업소수 (폐업으로 단정하지 않음)
16. 업종다양성 = 정규화 Shannon Diversity 0~100

추가 보조지표로 전세가격 YoY, 전월세 거래량 YoY, 상가 수 YoY, 의료·교육 업소/인구 1천명, 공매물건/1천세대, 상업용 거래 YoY, 청년 1인세대 비율, 고연령 1인세대 비율을 계산할 수 있다.

## Composite Index 4종
동일 월의 **경남 전체 유효지역 percentile(0~100)** 로 각 구성요소를 표준화한 뒤 가중평균한다. 결측치(N/A)는 0점으로 바꾸지 않고 해당 가중치를 제외해 재정규화한다.

### 1. 지역활력지수 `vitality_index`
- 인구 YoY 30%
- 청년인구비율 25%
- 상가 순증감 20%
- 주택 거래회전율 15%
- 소형가구비율 10%

### 2. 주거시장압력지수 `housing_pressure_index`
- ㎡당 매매가격 YoY 30%
- 월세화 비율 20%
- 1천세대당 공매물건수 20%
- 노후건축물 비율 15%
- 전월세 거래량 YoY 15%

> 높다는 것이 무조건 좋다는 뜻이 아니라 가격·임대·공매·노후도 등 **시장 압력이 상대적으로 높음**을 의미한다.

### 3. 생활편의지수 `living_convenience_index`
- 인구 1천명당 전체 상가수 35%
- 업종다양성 30%
- 인구 1천명당 의료 관련 업소 20%
- 인구 1천명당 교육 관련 업소 15%

### 4. 상권변화지수 `commerce_change_index`
- 상가 순증감 40%
- 상가 수 YoY 35%
- 업종다양성 15%
- 상업·업무용 거래 YoY 10%

## Peer Group
경남 전체 점수 외에 도시/도농복합/군지역 등 구조가 유사한 Peer Group 상대점수를 별도로 확장할 수 있다. Peer 선정은 인구규모·청년/고령·1인가구·공동주택 비율·주택가격·상가밀도 특성을 사용하며, 서비스 계산값은 Python에서 결정한다.

## N/A / 0 / 신뢰도
- `0` = 지표가 적용되지만 관측값이 0
- `N/A` = 지표 자체가 적용되지 않거나 자료 부족
- 거래가격은 `sample_size`와 `data_confidence(low/medium/high)`를 함께 표시한다.
- `source_as_of`, `fetched_at`, `is_provisional`로 원자료 기준시점과 수집시점을 분리한다.
