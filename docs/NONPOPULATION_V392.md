전체 잔여 수집이 끝난 후 지수48개월을 한 번 재계산하여 반복 계산 비용을 줄인다. 최종 지수도 재조회 비교하고 완료 기록을 남긴다. 자동 후속 실행16회 제한, 실행당 소스별6개월,120분 내부 예산/150분 작업 제한. 요청 제한·인증·집계 오류는 무조건 재실행하지 않는다. 결과 ZIP 업로드 실패는 별도 한번 재시도한다.
