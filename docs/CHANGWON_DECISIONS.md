# 창원 제출 범위와 비교 정책

- 2026-10-10 사용자 확정: 이번 제출은 창원 대상이며 경남 전체 확장은 이후 별도 실시한다.
- 인접 비교는 필수 규칙이 아니다. 유사 지역 및 무작위 비교도 유용하다.
- 공간 후보는 경계선 접함 또는 면적 겹침을 인정할 수 있다. 겹침은 공식 경계 수정이나 공식 인접관계 확정으로 표현하지 않는다.
- 경계 겹침 66쌍의 완전한 수정은 제출 선행조건이 아니다. 원본과 관계 종류를 보존한다.
- 인구 보완은 처음 사용한 공식 API와 통계 정의를 유지한다. 공식 CSV는 독립 대조용이며 Firebase 보완 자료로 전환하지 않는다.
- 인구 수집, 공식 총계 대조, 지수 재계산이 공간 후보 정책 적용과 프론트 제출 준비보다 우선이다.
