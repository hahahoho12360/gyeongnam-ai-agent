# 창원 비교 대시보드 v4.0

AI 채팅과 데이터 관리·대화 목록을 유지합니다. 상단 화면 모드 버튼, 9개 지표 선택, 같은 기준월 창원 최대·평균·최소 비교표, 46개 후보에서 분야별 무작위 질문 5개를 제공합니다. 모바일에서는 비교표를 지표별 카드로 표시합니다.

새 읽기 전용 API: `/api/analytics/regions/{region_id}/dashboard?answer_mode=basic`. Firebase에 쓰거나 공식 원 API를 호출하지 않습니다. 수집 액션이 완료될 때까지 기다릴 필요 없이 사용할 수 있습니다. 수집이 진행되면 다음 화면 조회에 기록이 반영됩니다.

비교월은 선택 지역의 마지막 저장 월입니다. 같은 월의 창원 비샘플 지역을 모집단으로 삼고 지표별 유효값 수를 표시합니다. 평균은 유효 지역별 값의 비가중 산술평균이며 시 전체 인구 총계, 전체 인구·세대로 계산한 비율, 전체 거래의 중앙값과 다릅니다. 최대·최소 동률 지역도 반환합니다. 결측·no_data·비유한 수치는 제외합니다. 청년 비율은 20~39세 원자료와 총인구, 1인세대 비율은 1인세대 원자료와 세대수가 모두 있어야 계산합니다. 지수는 같은 창원 산정 범위·월·방법 버전만 비교하며 재계산 대기 값은 제외합니다.

가격은 개별 아파트 매매금액(원)을 전용면적(㎡)으로 나눈 값들의 지역·월별 중앙값입니다. 표시만 소수점 이하 절사하고 저장·분석의 정밀도를 유지합니다. 가격 전년 대비는 전년 동월 ㎡당 중앙가격 대비 변화율입니다. 동일 주택의 가격 변동률은 아닙니다.

차트는 인구, 청년 비율, 1인세대 비율, 아파트 ㎡당 중앙가격, 가격 전년 대비, 지역활력, 주거시장압력, 생활편의, 상권활력 대리지수 9개입니다. 실제 달력의 월을 생성하며 빠진 월은 null로 두어 선을 연결하지 않습니다. 단위·관측 시작값·월을 표시합니다. 간단 모드는 12개월, 기본·상세 모드는 36개월입니다.

추천 질문은 클릭 시 선택 지역 전체명과 질문을 입력하며 자동 전송하지 않습니다. 첫 방문과 '다른 질문 보기' 버튼에만 변경됩니다. 자료가 없을 때는 수집 상태·분석 한계를 설명하도록 질문에 포함합니다.

배포: GitHub main 변경을 Render와 Vercel의 기존 Git 연동 자동 배포로 적용합니다. 프론트엔드와 백엔드 모두 새 버전이 필요합니다. 기존 수집 액션은 실행 당시 커밋에서 계속 진행하며 이번 화면 변경은 수집 코드와 Firebase 기록을 변경하지 않습니다.
